# Blog Anna Bella

Modelo de blog pessoal para uma influenciadora fictícia, feito com HTML e CSS como projeto de estudo.
Personal blog template for a fictional influencer, built with HTML and CSS as a learning project.

[🇧🇷 Português](#-português) · [🇺🇸 English](#-english)

---

## 🇧🇷 Português

### Sobre o projeto

Site de quatro páginas para a personagem "Anna Bella": **Home**, **Biografia**, **Campanha publicitária** e **Contato**. Os textos são de preenchimento (lorem ipsum). O projeto pratica a navegação entre páginas e a organização de imagens e textos.

### Tecnologias

- HTML5
- CSS3

### Como usar

Baixe o repositório e abra o `index.html` no navegador.

### Estrutura

```
index.html         página inicial
biografia.html     biografia
publicidade.html   campanha publicitária
contato.html       contato
style.css          estilos
images/            imagens
```
